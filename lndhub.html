Core Features & System Design

Architected for custodial service providers, families, and shared lightning infrastructure.

🔐

Isolated Accounts

Host thousands of individual sub-accounts on top of a single physical LND daemon without leaking channel details.

📱

Native App Integration

Fully compatible out-of-the-box with BlueWallet, Zeus, Alby, and any wallet supporting the LNDHub API spec.

⚡

Internal Transfers

Transactions between users hosted on the same LNDHub node settle instantly off-chain with zero routing fees.

🛠️

Self-Hosted Control

Run LNDHub on your own hardware (Umbrel, RaspiBlitz, MyNode) or host it on your cloud server via Docker.

LNDHub API Endpoints

Standard RESTful interface exposed for mobile and web frontends.

// 1. Create Account
POST /createaccount { "partnerid": "bluewallet" }

// 2. Generate Lightning Invoice
POST /addinvoice { "amt": 5000, "memo": "Coffee" }

// 3. Pay Lightning Invoice
POST /payinvoice { "invoice": "lnbc50n1..." }

// 4. Fetch User Account Balance
GET /balance
